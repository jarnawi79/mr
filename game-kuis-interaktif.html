✍️ Soal Buatan Guru

📘 Cara mengisi soal (3 pilihan)
  1. Ketik langsung: pertanyaan, pilihan A. sampai D. (SMA/MA/SMK/MAK sampai E.), baris Kunci: A, dan baris Pembahasan:. Pisahkan tiap soal dengan satu baris kosong.
  2. Dari Google Sheets / Excel: buat tabel 8 kolom — Pertanyaan, A, B, C, D, E, Kunci, Pembahasan (kolom E boleh kosong untuk PAUD–SMP/MTs) (satu baris = satu soal). Blok sel-selnya, salin (Ctrl+C), lalu tempel (Ctrl+V) di kotak di atas. Otomatis diubah ke format soal.
  3. Impor file CSV: di Google Sheets pilih File → Download → CSV; di Excel pilih Save As → CSV. Lalu klik “Impor file CSV”.
📊 Kirim nilai siswa ke Google Sheets (opsional)

Tempel Kode Sambungan dari Google Sheets Anda (lihat PANDUAN rekap nilai). Siswa akan diminta mengisi nama & kelas, lalu nilainya masuk otomatis ke spreadsheet Anda.

🔗 Bagikan ke siswa

Buat tautan berisi soal ini. Siswa cukup membuka tautan (misalnya lewat WhatsApp) lalu langsung bermain — tanpa perlu mengetik soal.
